Tellen en declarabiliteit

Wat meetelt in het weekoverzicht, de verhouding per uursoort en de declarabiliteit.

Agenda-analyse

Uursoorten met deze markering in de naam (standaard *, bijvoorbeeld Pauze*) gelden als niet-cliëntgebonden: ze vallen buiten de cliënttijd en staan niet bij Verhouding per uursoort. Weekenden tellen standaard niet mee.

Bijvoorbeeld do_not_declare (niet declareren), unavailability (afwezigheid) en presence (thuiswerken).

Declarabiliteit per profiel

De eerste regel waarvan de tekst in de profielnaam staat, bepaalt de grondslag. Direct: alleen directe tijd is declarabel (J&O/JBG). Clientgebonden: alle cliëntgebonden tijd, ook reistijd (JGGZ). Geen regel van toepassing: clientgebonden.

Functies

Zet onderdelen van de hulp aan of uit. Na publiceren geldt het voor iedereen die deze configuratie krijgt.

Google Maps

Met een Routes-sleutel deelt Afspraak maken de afspraken efficiënter in op rijtijd en vult het de reistijd in; Route van de dag berekent er de kortste volgorde mee. Met een kaartsleutel toont Route van de dag een kaart. Naar Google gaan alleen postcodes. Leeg laten: geen rijtijden en geen kaart.

Routes-sleutel

Deze sleutel komt in de extensie en is daar te zien. Beperk hem in Google Cloud tot alleen de Routes API en stel bij Quotas een maximum per dag in (bijvoorbeeld 1000) plus een budgetmelding. Wil je de sleutel geheim houden, gebruik dan een eigen server; die gaat voor en dit veld mag leeg blijven.

Eigen server (optioneel)

Voor server/routes-proxy.

Kaartsleutel

De kaartsleutel staat wel in de extensie. Gebruik daarom een aparte sleutel die in Google Cloud is beperkt tot alleen de Maps Embed API (kaarten tonen is daar gratis). Gebruik hier niet de Routes-sleutel.

Voorbeeldantwoorden en welke velden de extensie gebruikt

Alleen de genoemde velden worden gelezen. Cliënt- en persoonsgegevens (naam, BSN, geboortedatum, adres, telefoon, e-mail, dossier) worden nooit gebruikt.

Weekafspraken (events)

Gebruikt: type, date, start_time en end_time (of time_slot.duration), classes (declared, not-declared), hour_type, clients (alleen: is er een cliënt gekoppeld) en occurrence_id.

{
  "data": [
    {
      "occurrence_id": "07ea819430e59",
      "date": "2026-08-25",
      "start_time": "2026-08-25T21:05:00.000+02:00",
      "end_time":   "2026-08-25T22:05:00.000+02:00",
      "time_slot": { "duration": 3600, "travel_time_before": 8, "travel_time_after": 7 },
      "type": "event",
      "hour_type": "JW BG H10 Individuele BG midde",
      "classes": "not-declared",
      "clients": [ { "id": 11142 } ]
    }
  ]
}

Weekregistraties

Gebruikt: type (alleen "registration"), occurrence_id, date, clients (gekoppeld ja of nee). Items van uitgesloten typen (unavailability, presence) worden overgeslagen.

{
  "entries": [
    { "type": "registration", "occurrence_id": "07ea81892877e", "date": "2026-08-24", "clients": [ { "id": 11142 } ] }
  ]
}

Registratiedetails

Gebruikt: direct_time, indirect_time, travel_time_before en travel_time_after, start_time en end_time, hour_type.name en declaration.status (voor uitsluiting).

{
  "registration": {
    "occurrence_id": "07ea80691f411",
    "start_time": "2026-08-06T16:00:00.000+02:00",
    "end_time":   "2026-08-06T16:30:00.000+02:00",
    "direct_time": 0, "indirect_time": 30,
    "travel_time_before": 0, "travel_time_after": 0,
    "hour_type": { "id": 788, "name": "JW Traject" },
    "declaration": { "status": "created" }
  }
}

Cliënt zoeken

Gebruikt: de interne id van de cliënt die op display_name, name of sortable_name past (nooit external_id).

{
  "clients": [
    { "id": 11142, "external_id": 9702, "display_name": "Tamara Test", "sortable_name": "test" }
  ]
}

Uursoorten (product_list)

Storingen

Uitzoeken waarom de hulp iets niet doet, en het herstel centraal uitrollen.

Laad een of meer opgeslagen ONS-pagina's. De controle herkent per opname of het een agenda-, afspraak- of registratiescherm is en test de bijbehorende onderdelen. De extensie-zip is optioneel: zonder zip draait alleen de paginacontrole, met zip worden ook de code en config.json vergeleken. Voeg voor volledige dekking een agenda, een geopend afspraakformulier en een registratieformulier toe. Alles blijft in deze browser.

Kies beide bestanden om de controle te starten.

Wijst ONS een veld of knop anders aan dan de extensie verwacht, dan kan een ontwikkelaar een herstelde selector leveren als ui-selectors.json. Laad dat hier in; de selectors gaan mee in config.json en gelden na publiceren voor alle medewerkers, zonder nieuwe versie van de extensie.

Controleer op de echte ONS-pagina (ook in de shadow-DOM van webcomponenten) of alles wat de extensie nodig heeft er is, zonder eerst een pagina op te slaan. Kopieer het script, open ONS in Chrome of Edge, druk F12, kies Console, plak en druk Enter. Het script leest alleen; het wijzigt niets.

Draai het op elk scherm: agendaweek, geopende afspraak, registratieformulier. Groen: gevonden. Geel: niet op dit scherm. Rood: een onmisbaar onderdeel ontbreekt.

Maakt één ZIP met config, controlerapport, testmatrix en technische gegevens. ONS-pagina's en hun bestandsnamen gaan niet mee.

Nog geen pakket gemaakt.

De teksten van de probleemschermen staan bij Teksten (sleutels met probleem_).
